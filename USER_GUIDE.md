# Arthra User Guide

> **Arthra is a private record-keeping workspace for Indian personal finance.** It helps you capture financial context, understand patterns, and prepare a controlled handoff. It does not replace advice from a qualified accountant, tax professional, lawyer, insurer, lender, or investment adviser.

## Start here

When you sign in for the first time, Arthra opens a four-step **Quick Start** guide. Select **Next** to move forward, **Back** to revisit a step, or **Skip for now** to enter the workspace immediately. The guide can be opened again from the account menu, so skipping does not remove help.

| First action | Why it matters | Where to find it |
| --- | --- | --- |
| Add one transaction | Starts a trustworthy ledger and makes later insights meaningful. | Transactions → Add transaction |
| Set one budget | Creates a clear, visible monthly boundary. | Budgets → Set budget |
| Create a Space only when needed | Keeps shared financial context separate from personal records. | Expense Spaces → Create space |
| Review the month | Helps you inspect records before exporting or sharing anything. | Analytics and Reports |

## Everyday workflow

### Record a transaction

Open **Transactions**, then select **Add transaction**. Choose Income or Expense, enter the amount and date, add a clear description, and select a category or account when helpful. You may add a note, mark a relevant business record as GST-aware, and select CGST + SGST or IGST when that context is appropriate.

Attach a JPG, PNG, WEBP, or PDF receipt when it supports your record. The attachment is optional; Arthra does not require a receipt to save a transaction.

### Use smart receipt assistance carefully

For an image receipt, select **Suggest fields** after choosing the file. Arthra shows a confidence-labelled draft and does **not** save anything. Select **Apply reviewed suggestions** only after checking the proposed description, amount, date, GST setting, and category. PDF receipts remain attachable even when image suggestions are unavailable.

### Read budgets and insights

Budget labels show whether the current state is **On track**, **Near limit**, or **Over budget**. Read both the label and the percentage, rather than relying on color alone. Analytics uses your active Expense Space only; its recurring-expense and budget-risk cards are calculated from recorded entries and are not guarantees or instructions.

The optional **Create AI summary** action produces a concise text summary from authorised aggregate data in the active Space. It is presented separately from calculated signals, is never saved as a financial record, and is not professional financial advice.

### Share with intent

Expense Spaces support three roles. An **Owner** manages a Space, invitations, and its budgets. An **Editor** can work with permitted shared records. A **Viewer** can read the Space without changing it. Invite the least-privileged role that enables the other person’s work.

For an accountant or CA, use **Reports** to choose the relevant Apr–Mar financial year, download CSV, or create a time-limited link. Revoke a link as soon as it is no longer needed.

## Demo mode

Select **Try demo** on the home page for an immediate, safe walkthrough. The persistent `DEMO DATA` badge means every amount and record is fictional. Demo mode is read-only, static, and isolated from all real accounts. Select **Exit demo** at any time to return home and start a private workspace.

## Practical safety checklist

| Before you act | Check |
| --- | --- |
| Before saving a receipt-assisted draft | Confirm each proposed field against the original receipt. |
| Before inviting someone | Confirm the Space and choose the smallest useful role. |
| Before creating a CA link | Check financial-year scope and expiry, then revoke after handoff. |
| Before using an AI summary | Compare it with the calculated cards and your original records. |
| Before making financial decisions | Consult a qualified professional when personal circumstances require it. |

## Help and troubleshooting

If a finance screen cannot load, use its **Try again** control first. Your existing records are not changed by a loading failure. If a receipt suggestion or AI summary is unavailable, continue with manual entry and calculated insights; neither optional tool is required to use Arthra.
