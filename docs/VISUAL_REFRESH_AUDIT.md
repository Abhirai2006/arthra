# Public Visual Refresh Audit

## Existing README image findings

The current landing screenshots in `docs/screenshots/` are outdated. They show the earlier white-and-pastel presentation, including lavender, coral, cyan, and multicolour glow treatments. They no longer represent the published black-grounded public experience, and their long full-page framing makes the product hierarchy difficult to assess quickly in GitHub.

## Refresh direction

The replacement documentation images should show the current public landing and feedback experience in focused desktop and mobile frames. The public design will use a matte-black foundation, graphite surfaces, off-white type, and limited green/blue accents reserved for action, status, and data. Radial colour washes, luminous orb effects, and multi-colour cards should be reduced in favour of thin rules, solid surfaces, deliberate whitespace, and subtle depth.

## Scope boundary

This refresh applies to public landing, public feedback, footer, and documentation presentation only. Protected finance screens, financial data, application calculations, and authorization rules are not being restyled in this pass.

## Implemented matte system

The final public override removes radial colour washes, gradient buttons, large soft shadows, and pastel sections from the dark presentation. Near-black is now the base material; graphite provides elevation; off-white provides reading contrast; green marks confirmation and consent; blue is used only for emphasis and data cues. Public cards use thin rules, solid fills, and modest hover movement instead of glow-driven depth. The light theme retains a paper-like white ground with restrained green and blue accents, including corrected feedback-form panel contrast.

The README now uses four focused current captures rather than the earlier tall legacy images: desktop landing, desktop feedback, mobile landing, and mobile feedback. The images are stored through the project’s managed static storage and linked from the README so the screenshot section accurately reflects the current public experience.
